# Примеры

Все тексты здесь придуманы для иллюстрации. Компании, города и люди вымышлены, цифр из реальных источников нет.

| Файл | Режим | Что показывает |
|---|---|---|
| [01-audit-company.md](01-audit-company.md) | Аудит (разбор паттернов) | описание компании, где паттерны из восьми групп идут почти в каждой фразе |
| [02-cleanup-city.md](02-cleanup-city.md) | Чистка | рекламный абзац о городе, после чистки он становится короче |
| [03-cleanup-email.md](03-cleanup-email.md) | Чистка | рабочее письмо в тоне службы поддержки |
| [tech-signs-sample.txt](tech-signs-sample.txt) | скрипт | файл с техническими маркерами и склеенной ссылкой для `scripts/check_tech_signs.py` |

Аудит показывает, какие паттерны есть в тексте и насколько густо. Кто написал текст, он не определяет.
